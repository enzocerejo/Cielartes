# Glossaire

Chaque terme technique ou métier utilisé dans le projet, en une phrase.

[← Retour à docs/](README.md)

| Terme | Définition |
|---|---|
| **AE (auto-évaluation)** | Note que l'on se donne soi-même sur chaque critère d'un TP, sur quatre niveaux (de « Pas encore » à « Maîtrisé »). |
| **BTS CIEL** | Le BTS Cybersécurité, Informatique et réseaux, Électronique, dont les TP sont rangés dans ce site. |
| **Compétence (C01, C04…)** | Capacité du référentiel du BTS qu'un TP permet de travailler ; le code est celui du référentiel. |
| **CSS** | Langage qui décrit l'apparence d'une page web (couleurs, tailles, placement). |
| **draw.io** | Logiciel gratuit de schémas ; ses fichiers `.drawio` sont les sources modifiables des schémas réseau. |
| **Export / import JSON** | Sauvegarde de toutes les données du site dans un fichier texte, que l'on peut recharger dans un autre navigateur. |
| **GitHub Actions** | Service de GitHub qui lance automatiquement des tâches (ici, la mise en ligne) quand on envoie des modifications. |
| **GitHub Pages** | Service de GitHub qui héberge gratuitement un site statique. |
| **Hash** | Partie de l'adresse après le `#` (par exemple `#tps`) ; le site s'en sert pour savoir quelle page afficher sans recharger. |
| **HTML** | Langage qui décrit le contenu et la structure d'une page web. |
| **IndexedDB** | Base de données intégrée au navigateur ; le site y garde les fichiers déposés dans les TP. |
| **JavaScript** | Langage de programmation exécuté par le navigateur ; il rend la page interactive. |
| **localStorage** | Petit espace de stockage du navigateur ; le site y garde les TP, notes et réglages. |
| **Markdown** | Façon simple de mettre en forme du texte (`**gras**`, listes avec `-`) ; utilisée dans les étapes et les notes. |
| **Normaliser** | Compléter ou corriger des données anciennes pour qu'elles aient la forme attendue par le code actuel. |
| **Point d'entrée** | Le fichier par lequel tout commence ; ici `site/index.html`. |
| **Routeur** | Partie du code qui choisit la page à afficher selon l'adresse ; ici la fonction `route()`. |
| **Seed (TP fourni)** | TP livré avec le site et ajouté automatiquement une seule fois aux données de l'utilisateur. |
| **Serveur local** | Petit programme lancé sur son PC (`python -m http.server`) qui sert le site comme s'il était en ligne. |
| **Site statique** | Site fait uniquement de fichiers (HTML, CSS, JavaScript) envoyés tels quels, sans programme côté serveur. |
| **TP** | Travaux pratiques : séance où l'on réalise une manipulation guidée, avec un sujet, des étapes et un rendu. |
| **Workflow** | Fichier de `.github/workflows/` qui décrit une tâche automatique de GitHub Actions. |
